# 257 Franklin Street Records Tracker

A one-page site that tracks Freedom of Information Law requests about the
environmental condition of a proposed elementary school site in Greenpoint,
Brooklyn. Published at https://physioautonomy.com.

- `requests.toml` holds the requests, their status, timeline and received records.
- `build.py` turns it into `docs/index.html` (run `python3.13 build.py`).
- `docs/` is what GitHub Pages serves.
